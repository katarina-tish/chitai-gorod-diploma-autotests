# Дипломный проект: автотесты «Читай-город»

Набор UI- и API-автотестов для публичных сценариев интернет-магазина
[«Читай-город»](https://www.chitai-gorod.ru/). Проект продолжает финальную
работу по ручному тестированию: автоматизированы сценарии поиска книги и
безопасные запросы поискового API. Операции с заказами, оплатой, отменами и
персональными данными намеренно не выполняются.

## Что проверяется

- UI: наличие поиска на главной странице; поиск по полному и частичному
  названию; поиск по автору; понятное состояние для неизвестного запроса.
- API: подсказки, поиск книг, популярные фразы и негативные проверки валидации
  поискового сервиса.

Всего: **5 UI-тестов и 5 API-тестов**. Тесты помечены маркерами `ui` и `api`.

## Структура

```text
.
├── src/
│   ├── api_client.py       # HTTP-клиент и анонимная авторизация
│   ├── config.py           # настройки из переменных окружения
│   └── pages.py            # Page Object поисковой страницы
├── test/
│   ├── conftest.py         # фикстуры браузера и API-клиента
│   ├── test_api.py         # API-тесты
│   └── test_ui.py          # UI-тесты
├── .env.example            # пример безопасных настроек
├── pytest.ini              # регистрация маркеров
└── requirements.txt
```

## Установка

Требуется Python 3.11+ и установленный Google Chrome. Selenium Manager сам
подбирает драйвер, поэтому `chromedriver.exe` в репозитории не хранится.

```bash
git clone <URL_репозитория>
cd chitai-gorod-diploma-autotests
python -m venv .venv
```

Windows:

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

macOS/Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

При необходимости скопируйте `.env.example` в `.env` и измените только
публичные параметры запуска. Токены и логины не нужны: клиент на время теста
получает новый анонимный токен по штатному API-маршруту и не записывает его на
диск.

## Запуск

```bash
# Только UI
pytest -m ui --alluredir=.allure_results

# Только API
pytest -m api --alluredir=.allure_results

# Все тесты
pytest --alluredir=.allure_results

# Показать окно браузера при UI-прогоне
HEADLESS=false pytest -m ui

# Проверка PEP8
flake8 src test
```

Для формирования Allure-отчёта при установленном Allure CLI:

```bash
allure serve .allure_results
```

## Архитектура и качество

- Page Object отделяет UI-селекторы от тестовых сценариев.
- HTTP-клиент инкапсулирует анонимную авторизацию и запросы API.
- Адреса и параметры запуска вынесены в переменные окружения.
- Все методы имеют аннотации типов; действия и проверки отражены в
  `allure.step`, тесты снабжены `@allure.title` и `@allure.story`.
- `.gitignore` исключает секреты, кэш, результаты запуска и бинарные файлы.
